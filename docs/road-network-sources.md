## 현재 결정: 자동화 확장 종료 (2026-10-07)

- 승인된 주소정보 도로 도형에 관해 사용자가 제시한 조건에는 국외 반출 금지, 인터넷·내비게이션·모바일 등을 통한 좌표 표시 제한, 비공개·공개제한 시설 관련 제한 및 보안규정 준수 의무가 있다. 이것은 사용자 제공 조건에 따른 프로젝트 중단 결정이며 모든 공간자료에 대한 법률 판단은 아니다.
- 해당 제한 원본은 열기, 내용 추출, 프로젝트 폴더로 복사, AI 도구 전달, GitHub 커밋, Vercel 업로드를 하지 않는다. 주소 텍스트만 추출하면 제한을 피할 수 있다고 가정하지 않는다. 국내 리전 또는 비공개 저장소 설정만으로 이용 허용이 확인된 것으로 취급하지 않는다.
- 이번 결정으로 기존 공개 자료나 코드를 삭제하지 않는다. 표준노드링크 및 경기도 공개 도로대장과 승인형 제한 자료를 혼동하지 않는다. 기존 raw 폴더의 Git/배포 제외 설정은 유지하되 이것만으로 보안이 보장된다고 설명하지 않는다.
- 현재 도로명 수집은 카카오 좌표 샘플링 방식 그대로 둔다. 공간 도형과의 교차 판정 또는 모든 도로의 완전한 조사라고 설명하지 않는다.
- 도로 전체 기점·종점과 전체폭(보도 포함)·차도폭은 수동 조사로 유지한다. 개별 링크의 끝, 도로대장 구간의 끝, 조사 범위의 끝으로 전체 도로 기종점을 대신하지 않는다. 기종점/폭원 근거와 기준일을 별도로 보존한다.
- 직전 로컬 변경은 테스트 190개 및 빌드가 통과했지만 커밋·운영 배포하지 않았다. 이번 작업은 중단 기록만 추가하며 추가 배포를 뜻하지 않는다.

재개를 요청받더라도 공개 서비스 활용·국외 전송·파생 결과 공개에 대한 제공기관의 허용 여부부터 확인한다. 현재 후속 작업에서는 가로망 확장을 제외한다.

## 날짜의 의미

- 자료 기준일: 원자료가 실제로 나타내는 시점. 연도/연월만 제공되면 정밀도를 유지하며 임의의 일자를 붙이지 않는다.
- 조회일: 앱이 API 응답을 받아 도로명을 수집한 시점. ISO 시간으로 저장하고 화면에서는 한국 날짜로 표시한다.
- 다운로드일/수집일: 파일을 확보한 시점. 자료 기준일로 대체하지 않는다.
- 게시/수정일: 제공기관 목록의 게시정보. 개별 도로 현황의 측량일로 간주하지 않는다.

현재 카카오 샘플링 결과는 도로명에 한해서 조회일을 기록하고 자료 기준일은 미확인으로 남긴다. 수동 추가 및 이전 저장자료의 날짜를 현재 날짜로 보정하지 않는다. 기준일 입력값과 조회일은 초안/JSON 백업에 보존하며 가로망 보고서 문구에도 포함한다.

## 공식자료 연결 시 설계

기종점은 도로 전체 기준, 전체폭(보도 포함)/차도폭/차로수는 조사영역 내부 구간 기준으로 분리한다. 각 항목에 값, 단위, 출처, 자료 기준일, 취득일, 연결 신뢰도, 확인 상태를 보존한다. 서로 다른 출처의 날짜를 하나의 최신 날짜로 합치지 않는다. 행에는 출처별 기준일 목록 또는 날짜 범위를 표시하고 상세보기에는 항목별 날짜를 제공한다. 폭 정의가 확인되지 않은 ROAD_BT는 전체폭으로 확정하지 않는다.

현재 변경은 자료 보관 및 날짜 표시이며, 다운로드 CSV를 이용한 도로 검색/폭/차로수 자동 연결은 아직 활성화하지 않았다.

## 도로 전체 기종점 연결 준비

2026-10-07 다운로드 폴더의 `[2026-09-14]NODELINKDATA.zip`을 읽어 `MOCT_LINK.dbf`와 `MOCT_NODE.dbf`가 있는 것을 확인했다. 링크의 `F_NODE`/`T_NODE`는 도로 전체의 공식 기점/종점으로 사용하지 않는다. `경기도도로대장(도로대장총괄).csv`의 시점명/종점명 역시 노선번호/구간번호 기준이며 도로명 전체 기종점으로 대체하지 않는다. 이 두 파일은 이번 작업에서 이동하거나 수정하지 않았다.

도로명 기종점 원본은 아직 확인되지 않았다. 신청 자료의 실제 스키마, 도로명 식별자, 관할/공동 도로 처리, 기종점 속성 및 기준일을 확인한 뒤 자동 연결을 구현한다. 승인된 파일 없이 임의의 샘플 좌표나 링크 끝을 공식 기종점으로 생성하지 않는다.

Step 1은 도로명 근거와 기종점 근거(`endpointSource`, `endpointReferenceDate`)를 분리한다. 기종점은 수동 입력이며 자동검증 미수행으로 표시한다. 전체폭(보도 포함)과 차도폭은 `totalWidth`, `carriagewayWidth`에 수동 입력하고, 폭원 근거는 `widthSource`, `widthReferenceDate`에 별도로 기록한다. 빈 값은 0이 아닌 `수동 조사필요`이며 JSON 백업 및 보고서 문구에도 구분을 유지한다. 표의 준비 작업은 자동 기종점 조회 완료를 뜻하지 않는다.
