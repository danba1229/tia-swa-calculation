| 자료 | 공식 공개 안내에서 확인한 범위 | 이번 접근 결과 | 앱 반영 |

| 전국도로안전표지 표준데이터 | 도로별 주의·규제·지시 표지의 위치 관련 자료 | 공식 목록 검색 색인은 확인, 상세 원문 503. 서울 수록 범위·실제 좌표/표지번호 컬럼 및 최신 파일 미확보 | 보조자료 링크, 서울 범위와 번호 대응 미확인 안내 |

503은 이 조사 환경의 접속 결과이며 사이트가 일반 사용자에게도 중단되었다는 의미가 아니다. 검색엔진의 생성형 요약을 개별 시설 원본 데이터로 사용하지 않았다. 인증 또는 접속 제한을 우회하지 않았다.

- 경찰청 서비스 개시 보도자료: https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1002&q_bbscttSn=20251218072753613
- 정밀도로지도 안내: https://map.ngii.go.kr/ms/pblictn/preciseRoadMap.do
- 서울시 도로별 도로표지: https://data.seoul.go.kr/dataList/OA-15015/S/1/datasetView.do

향후 실제 자료 확보 시에는 같은 시설 여부를 관리번호·좌표·표지종류·방향·기준일로 대조해야 한다. 근접 좌표 또는 번호의 일치만으로 합치지 않는다. 보조자료가 있어도 모든 자료의 추가 확인 전제는 유지한다.

## 카카오 로드뷰

공식 문서 https://apis.map.kakao.com/web/guide/#roadviewurl 를 HTTP 200으로 읽어 `https://map.kakao.com/link/roadview/위도,경도` 형식을 확인했다. 좌표 또는 장소 ID로 해당 위치의 로드뷰를 실행하는 공식 링크다.

앱은 SVG 번호 링크와 선택 상세의 링크에 해당 표지 레코드의 좌표를 전달하고 `target=_blank`, `rel=noopener noreferrer`로 연다. 좌표 누락·공란·비정상 숫자는 링크를 생성하지 않는다. 위치의 로드뷰 실행과 그 화면에서 해당 표지판을 판독할 수 있는지는 별개이며, 촬영일·방향·가림·영상 부재를 사용자에게 안내한다.

단위검증은 좌표 순서/잘못된 좌표 처리/원본 코드 보존을 확인한다. 브라우저 검증은 테스트용 도착 페이지를 사용해 실제 새 탭 생성 및 클릭한 시설의 좌표 전달을 확인한다. 실제 로드뷰 사진을 판독하거나 모든 시설의 영상 존재를 검증했다는 뜻이 아니다. 카카오 지도/주소 검색/지도 타일은 기존 실제 응답으로 계속 검증한다.
