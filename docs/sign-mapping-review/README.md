# 서울시 미대응 표지판 코드 상세 검토 및 매핑 입력표

검토일: 2026-10-12. 서울시 안전표지 2026-02-13 원본 중 앱에 채택된 220,087건을 대상으로 한다. 비교 기준은 경찰청 교통안전시설 일람표 2023.12 시행판이다. 서울 전체 현재 실시간 시설 현황 또는 2026년 최신 법령 전수 검증 결과를 뜻하지 않는다.

- 미대응 비공란 코드 94종, 37,335건. 코드 누락 45건을 더하면 37,380건이다.
- 표기 변환 후보 8종 353건 / 노면표시 번호 충돌 22종 892건 / 대응 번호 없는 코드 64종 36,090건.
- 별도 도로안내표지 R 자료 12,008건은 이 94종에 포함하지 않는다.
- 아래 내용 설명은 원본 DBF의 자유서술 비고 RMK를 근거로 한 관찰이다. 서울시가 공표한 코드 명칭 사전이 아니다. 비고에는 문구 외에도 정비사항·LED 등 설치방식이 포함된다.
- 현재 앱의 ‘비고’에는 서울시 원본 코드를 보존해 보여준다. 이번 표의 ‘원본 비고’는 분석에 별도로 읽은 DBF RMK이므로 서로 다른 항목이다.
- 코드가 일람표와 숫자로 일치하는 기존 124종도 시설별 의미 전수 검증이 끝난 것은 아니다. 본 표는 현재 후보 번호를 표시하지 못하는 코드 목록이다.
- 서초 예시는 남부순환로 2584(37.483625, 127.032683), 가로 500m × 세로 500m이다.

## 입력 방법

엑셀 ‘매핑 입력’ 시트의 마지막 3개 노란색 열(사용자 지정 일람표 번호, 사용자 표시명, 적용 조건 및 예외)에 작성한다. 조건 없이 코드 전체에 적용할 경우 그 뜻을 명시한다. 도로명 안내처럼 적합한 일람표 번호가 없는 것은 번호를 비워 두고 사용자 표시명을 지정할 수 있다. 751 등 혼합 코드는 관리번호별 예외 또는 확인 가능한 조건이 필요하다. 원본 코드는 보존한다. 아직 앱에 매핑을 적용한 것은 아니다.

## 출처 및 재현

- 서울시 안전표지 관련 정보: https://data.seoul.go.kr/dataList/OA-15540/S/1/datasetView.do
- 경찰청 일람표 게시글: https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1001&q_bbscttSn=20240521062714460
- 일람표 PDF는 기존 검증에서 확보한 서로 동일한 공개 재게시본을 사용했다. 경찰청 서버 원본과의 바이트 대조 및 이후 개정사항 검증은 미완료다.
- 원본 DBF를 앱 스냅샷의 안전표지 관리번호 집합으로 제한해 집계했다. 95개 행(공란 포함) 모두 기존 코드 비교표 건수와 일치하며 관리번호 중복이 없음을 확인했다.
- evidence.json: 코드별 전체 비고 빈도와 대표 관리번호·좌표. 엑셀 원본 비고 전체 시트에도 모든 고유 비고와 건수를 담았다.
- 시트의 로드뷰 링크는 표본 위치를 여는 공식 링크이며 영상 존재나 표지판의 현재 상태를 보장하지 않는다.
