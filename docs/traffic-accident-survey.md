# Step.8 교통사고 자동 조사

## 사용 순서

1. 화면 상단의 **주소지**에 상세 주소를 한 번 입력한다. 입력을 멈추면 위도·경도를 자동 계산하고 Step.8에도 같은 주소와 좌표를 표시한다. 주소 입력칸과 사업지 좌표 입력칸을 Step.8에서 별도로 제공하지 않는다. 조회 실패 시 상단 **좌표 다시 확인**을 누르거나 주소를 수정한다.
2. 반경(10~2,000m), 기준 연도, 조사 기간(1~5년)을 정한다. 예: 기준 연도 2025, 3년이면 2023~2025년을 각각 조사한다.
3. 필요하면 교차로를 최대 10개 추가한다. 각 교차로의 중심 좌표와 반경을 입력한다. 교차로는 기준 연도 1년을 조사한다.
4. 좌표 계산 후 **자동 조사 시작**을 누르면 시군구 통계와 TAAS 반경 집계가 차례로 표시된다. 상단 주소가 바뀌면 이전 주소의 진행 중인 사고 조사를 취소하며, 이전 결과의 내보내기를 차단한다. 반경·연도 변경 시에도 다시 조사해야 한다. 사고 조회는 버튼을 눌러 시작하며, 주소 입력만으로 외부 사고 조회 전체를 실행하지 않는다.
5. **결과 엑셀 다운로드**에서 보고서 표와 기존 조회자료를 함께 받는다. 앞쪽 `보고서_지역별`, `보고서_사업지주변`, `보고서_보행자자전거_연도`, `보고서_교차로`는 화면과 동일한 표이다. 뒤쪽 `년도별 사고`, `사업지 주변`, `보행자사고`, `자전거사고`, `교차로사고(n)` 및 출처·조건 시트는 원래 조회값과 검증 내역을 보존한다. 오류/자료 없음은 별도 상태이며 숫자 0으로 대체하지 않는다.

## 보고서 표 양식

260630 노원우체국 2장 2.1.11의 표 제목·열 순서·병합 머리글·단위를 기준으로 화면 및 엑셀 표를 구성한다. 지역명, 연도, 반경, 교차로명, 값은 조사 결과와 조건에서 가져오며 원본의 서초구·서울교대 표기를 복사하지 않는다. 기존 조사 자료도 재조회 없이 표로 변환된다.

- 지역 통계: 구분 / 발생건수(건) / 사망자수(명) / 부상자수(명), 마지막 행 연평균 증가율(소수점 2자리). 선택 기간의 전체사고만 사용하며, CAGR은 실제 연도 차이 기준이다. 기간 누락·첫해 0·1개 연도는 산정 불가이다. 시도 전체 자료는 현재 수집하지 않으므로 시군구 자료를 시도 통계로 표기하지 않는다.
- 주변 사고: 연도별 5개 심각도 지표 뒤에 사고유형(차대차·차대사람·차량단독) 병합 머리글을 둔다. 현재 미수집한 사고유형은 `미수집`으로 명시한다.
- 보행자·자전거: 조회한 연도마다 ① 보행자, ② 자전거 두 행을 표시한다.
- 교차로: 지정 번호와 이름별 표. 조회 완료이며 5개 지표 모두 0인 지점만 원본처럼 사고 없음 주석으로 옮긴다. 실패·미조회는 표에서 누락하지 않으며, 교차로 합계를 만들지 않는다.
- 사상자 원문 합계, 조회 오류와 제공 범위는 표 아래 주석 및 검증 내역에서 확인한다. 엑셀에는 병합, 테두리, 숫자 서식, 증가율 수식, 인쇄 영역을 지정한다. HWP 자동 삽입이나 원본 문서 편집은 포함하지 않는다.

## 자료의 의미

| 자료 | 범위 및 집계 |
|---|---|
| 년도별 사고 | 입력 좌표가 속한 시군구 전체. 공단의 시군구 구분상 일반구를 합친 시 단위일 수 있으며 응답 지역명을 그대로 기록한다. |
| 사업지 주변 | TAAS 반경 내 전체 사고. 사망·중상·경상·부상신고를 모두 선택한다. |
| 보행자/자전거 | 같은 반경과 연도에서 TAAS 사고부문을 각각 선택한다. 두 항목은 전체 사고와 별도로 조회하며 서로 합산하지 않는다. |
| 교차로사고(n) | 사용자가 지정한 교차로 중심 반경 내 **전체 사고**. 도로형태가 교차로인 사고만 필터링한 통계가 아니다. 반경이 겹칠 경우 교차로별 합계를 전체 사고수로 사용하지 않는다. |
| 다발지역 참고 | 공단 선정기준에 따른 다발지역 중 중심점이 반경 안에 있는 지점. 각 지점의 사고수는 사업지 반경 내 사고수가 아니다. 보행자 자료는 최근 3년의 선정기준을 사용한다. |

엑셀은 반경별 **집계 결과**이며 개별 사고 원자료가 아니다. 개별 사고의 시간대·사고유형·법규위반별 상세표, TAAS 원본 사고목록 자동 다운로드, HWP 보고서 삽입은 이 기능에 포함하지 않는다.

TAAS의 `사상자수` 표기가 사망·중상·경상·부상신고 합계와 다른 실제 사례가 확인되었다. 원문 숫자를 임의로 고치지 않고 `사상자(TAAS 표기)`로 보존하며 화면과 엑셀에 원문 합계 확인 경고를 남긴다. 보고서 확정 전 이 경고를 확인해야 한다.

## 서버 설정

`KOROAD_API_KEY` 하나로 통계·자전거·보행자 API를 호출한다. URL 인코딩된 키와 디코딩된 키를 모두 지원하며 한 번만 디코딩한 후 요청 파라미터로 인코딩한다. 키를 `NEXT_PUBLIC_` 변수로 만들지 않는다.

기존 `KAKAO_REST_API_KEY`로 상세 주소→좌표 및 좌표→법정동을 확인한다. 공단 통계 API의 4자리 시군구 코드와 다발지역 API의 법정동 코드를 혼용하지 않는다. `lib/koroadRegions.json`은 2026-10-05 공식 요청변수 코드표에서 생성했으며 공식 표의 제주도 표기를 제주특별자치도로 정규화했다. 행정구역 변경 시 공식 코드표를 갱신한다.

TAAS 반경 조회에는 별도 인증키가 없다. 서버가 공개 TAAS 화면에서 연도·반경·심각도·사고부문을 설정하고 EPSG:5181 좌표 엑셀을 업로드한다. 지점마다 임의 식별자를 사용해 새 조회의 결과임을 확인하고 응답 좌표 및 사상자 합계를 검증한다. 새 로그인/보안확인이 생기면 우회하지 않고 조회 실패로 표시한다.

Vercel Node.js 함수는 서울 리전에서 Chromium/Playwright를 실행한다. 함수 제한은 반경 조회 180초, 공단 API 90초이며 앱은 한 번에 한 조회씩 실행한다. 동일 인스턴스의 중복 작업은 제한하고 성공한 동일 조건은 메모리에 1시간 저장한다. 캐시는 영구 저장이나 인스턴스 간 공유가 아니다. 입력·완료된 결과는 해당 브라우저에 저장되며 전체 초기화 시 함께 삭제한다.
