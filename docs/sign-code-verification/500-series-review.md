# 서울시 500번대 안전표지 재검토

검토일: 2026-10-12. 대상은 앱 채택 서울시 안전표지의 500번대 57종, 1,830건이다. 원본 RMK가 있는 자료는 1,056건, 공란은 774건이다. 비교 기준은 앱에서 사용하는 경찰청 「교통안전시설 일람표」 2023.12 시행판이며, 2026년 최신 법령 전수 검증을 뜻하지 않는다.

## 결론

일람표에 대응되는 **내용 또는 도안은 일부 존재**한다. 그러나 이번 검토로 **서울 코드 하나를 모든 레코드에 동일한 경찰청 번호로 확정할 수 있는 코드군은 확인하지 못했다.** 코드의 공식 정의, 원본 비고의 의미, 실제 사진의 개별 표지를 구분해야 한다. 아래는 2026-10-12 검토 결과이며 당시에는 앱 매핑에 새로 적용하지 않았다. 이후 2026-10-13 사용자가 514 계열과 513의 두 문구를 지정하여 PR #6에 규칙을 추가했다. 같은 날 526·521·538·563의 조건부 매핑 및 540·543·532·534 표시 제외를 추가했으며, 559는 서초동 실제 사례를 확인한 뒤 사용자가 표시 제외로 지정했다. 전체 잔여 매핑 목록은 README의 최신 항목을 참고한다. 최신 사용자 지정 규칙은 [README](README.md)의 해당 날짜 항목을 참고한다.

## 비슷한 의미를 정확한 단일 번호로 간주하면 안 되는 사례

- 540: 눈·비·안개 시 감속운행은 기상상태(410)와 통행주의(415)의 의미가 결합된 문구다. 일람표 410 예시는 ‘안개지역’, 415 예시는 ‘속도를 줄이시오’이며 복합 안내 전체가 어느 한 도안과 같다고 확인한 것은 아니다. 비고 공란 9건과 미끄럼주의 문구도 있다.
- 543: 5건 모두 소방관서 앞 긴급차량주의 관련 비고이지만, 이 문구의 독립 표지가 일람표의 어느 도안과 동일한지 확인되지 않았다. 주의 내용이란 이유로 415를 확정하지 않는다.
- 555·556·557·559·562: 좌회전시, 좌회전신호시, 보행신호시, 동시신호를 구분한다. ‘좌회전시’는 동작 조건일 수 있으므로 모두 407로 처리하지 않는다.
- 504-1·527·528·531·535·536: 시간, 요일, 주차허용, 차량 예외, 구간이 섞인다. 주차허용을 주차장(319)과 동일시하지 않으며 시간만 보고 405·406을 일괄 선택하지 않는다.
- 541·564: 주차구획선 외 주차금지 또는 거주자우선주차 안내를 주차금지(219) 하나로 줄이면 조건이 사라질 수 있다.
- 544: 중량제한, 화물자동차 통행제한, 높이·폭·길이 등의 조합이다. 220 차중량제한과 203 화물자동차 통행금지를 혼동하지 않는다.
- 510-1·567: ‘회전차량우선’을 회전교차로(304)나 통행우선(332)로 바로 연결할 수 없다. 일람표 332는 서로 마주 보는 빨간/흰색 화살표 도안으로 단순 문구와 동일하다고 볼 수 없다.
- 522 장애물표적·반사판, 529·561 막힌도로, 532 사고잦은곳, 534 단속안내, 566 사전예측 출발금지 등은 현재 일람표에서 해당 문구와 정확히 같은 단일 표지 도안을 확인하지 못했다. 이것이 시설에 대한 공식 분류나 다른 매뉴얼에도 없다는 뜻은 아니다.
