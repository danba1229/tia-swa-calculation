# 자전거·횡단보도·기타 751 도안 판독 — 2026-10-13

## 적용 기준

사용자가 승인한 표시 규칙이다. 서울시의 공식 코드 사전이나 공식 검증 완료를 뜻하지 않는다. 원본 코드·비고·관리번호는 보존하고 모든 지점의 추가 확인 안내와 단일 파란색을 유지한다.

- 자전거주의: 빨강/노랑 삼각형 자전거 도안이면 134, 흰색 문구만 있으면 제외한다. 문구만으로 모양을 추정하지 않는다.
- 자전거전용도로 302, 자전거·보행자 겸용도로 303, 자전거전용차로 318. 해제는 해당 번호와 427 조합이다. 전체 비고가 명확한 유형과 일치하는 경우에만 자동 연결한다. 연서로/연세로는 원문에 있는 정확한 접두어만 허용한다.
- 횡단보도: 빨강/노랑 삼각형 132, 파란 지시 도안 322, 그림 없는 문구판은 제외한다. 원본 751의 ‘횡단보도’ 문구만으로 132/322를 선택하지 않는다.
- 우로굽은도로 111, 좌로굽은도로 112는 앱 채택 경찰청 일람표와 일치한다. 문구만 있는 판과 실제 도안이 있는 판을 사진으로 구분한다.
- **흰색 큰 판에 표준 그림과 문구가 함께 들어 있으면 문구만 있는 판이 아니다.** 다른 지점에서 같은 비고가 나와도 사진 판독을 자동 전파하지 않는다.
- 이번 지점별 판독은 관리번호·751·비고·좌표가 모두 일치할 때만 적용한다. 재수집으로 비고/좌표가 바뀌면 재검토한다. 사진은 촬영 시점의 관찰이며 현재 상태를 보증하지 않는다.
