# 751 자전거주의와 경찰청 134번 대조 — 2026-10-13

사용자 조건은 ‘실제 자전거주의 표지가 경찰청 일람표 134번과 같다면 134로 처리’다. 실제 판독 가능한 송파구 사례는 134 도안과 다르므로, 이번에는 751의 자전거주의를 일괄 매핑하지 않는다. 원문 자전거주의 47건, 공백·슬래시·LED 변형 포함 59건을 보류한다.

## 일람표

앱의 [경찰청 교통안전시설 일람표 2023.12 시행판](../../public/reference/police-sign-chart-2023-12.pdf)에서 **134 자전거**는 빨간 테두리·노란 바탕의 삼각형 안에 검은 자전거 그림이 있는 주의표지다. 파란 원형 자전거 전용도로 표지나 흰색 문구 보조판과는 도안이 다르다.

## 조사 범위와 결정

봉천로 `04-0000360192`, 여의도 `04-0000042435`의 인근 사진도 열었으나 가까운 촬영점에서 표지 정면을 확실하게 판독하지 못했다. 해당 지점의 형태는 결론내리지 않는다. 송파구 사례 역시 사진에서 관리번호를 직접 읽은 것이 아니라 원본 좌표·비고와 인근 시설을 대조한 관찰이다.
